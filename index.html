How to set up GitHub Gist

  1. Generate a GitHub Personal Access Token (PAT):
    Go to github.com/settings/tokens
    Click "Generate new token (classic)"
    Check "gist" permission only
    Click "Generate token" and copy it immediately
  2. Create a new Gist:
    Go to gist.github.com
    Name the file: updates.json
    Paste this content:
    [{"version":"v1.0.0","date":"2026-01-01","desc":["First update!"],"tags":["NEW"]}]
    Make it Public (so everyone can read it)
    Click "Create public gist"
  3. Copy the Gist ID from the URL:
    https://gist.github.com/yourusername/YOUR_GIST_ID
  4. Paste both below and click "Save Settings".
Important: The GitHub Personal Access Token is like a password. Keep it secure and only use it for this purpose. Never share it publicly.
Everyone can READ the gist (it's public), but only you can WRITE to it (using the token).
